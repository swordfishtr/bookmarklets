General usage:

Copy the desired script and process it with a Javascript minifier. Make sure the result is all 1 line and starts with `javascript:void function()` -- change it if need be. Create a bookmark in your browser and edit it (possibly by right clicking it). Give it an appropriate name, and paste the script into the URL section. Make sure again the URL starts with `javascript:` because some browsers silently remove this part. Then, follow the instructions of the specific script.

These are mostly for personal use, or made for a friend. PRs without awareness of context are likely to be rejected.
